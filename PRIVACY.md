# Privacy Policy — EloSight

**Last updated:** August 29, 2026

EloSight is an unofficial browser extension for FACEIT. This policy describes how the extension handles information.

## Summary

EloSight **does not collect, sell, or transmit personal data** to any server operated by the extension author.

## Data stored locally

The following is saved in your browser via `chrome.storage.sync` (Chrome sync may apply if enabled):

- Extension settings (feature toggles)
- Your FACEIT API key (if you choose to enter one)

This data stays on your device / in your browser account and is not sent to third parties by EloSight.

## Data accessed

When you use EloSight on faceit.com, the extension:

- Reads public match and player data from FACEIT pages and the [FACEIT Data API](https://docs.faceit.com/docs/data-api/data) (using your API key if provided)
- Intercepts FACEIT API responses already loaded by the FACEIT website to display analytics

EloSight does not access passwords, payment information, or private messages.

## Third parties

- **FACEIT** — API requests go directly to `open.faceit.com` when an API key is configured
- **Google Chrome / browser vendor** — standard extension platform behavior

## API keys

Do not share your FACEIT API key. Do not publish it in source code or screenshots. Each user should use their own key.

## Children

EloSight is not directed at children under 13.

## Changes

This policy may be updated. Continued use of the extension after changes constitutes acceptance.

Open an issue on the GitHub repository for privacy questions.
